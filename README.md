# Shard Economy Mod

A server-side Fabric mod for Minecraft 1.21.11 inspired by EconomyCraft with NO money limit (64-bit integer balance).

## Features

- 64-bit integer balance for virtually unlimited currency
- Starting balance and rulebook for new players
- Commands for checking balance, paying other players, selling items, buying diamonds, and viewing rules

## Requirements

- Minecraft 1.21.11
- Fabric Loader 0.14.0 or higher

## Installation

1. Download the mod from the releases page.
2. Place the mod file in your server's `mods` folder.
3. Start your server.

## Usage

### Commands

| Command | Description |
|---------|-------------|
| `/bal` | Check your current balance. |
| `/pay <player> <amount>` | Pay another player a specified amount of Shards. |
| `/sell` | Sell the item you are holding. |
| `/buy <amount>` | Buy diamonds with Shards. |
| `/rules` | View the server rules. |

## Configuration

The mod does not have a configuration file. All settings are hardcoded in the mod.
